# محدوده‌ی محصول

وضعیت سند: پیش‌نویس فاز ۰

تاریخ: 1405/09/04

منبع ردیف‌های این سند پیوست قابلیت‌های فاز ۰ است. توضیح کوتاه هر ردیف همان قابلیت را بازگو می‌کند و قابلیت تازه‌ای اضافه نمی‌کند.

## 1. برچسب‌های امکان‌پذیری

| برچسب | معنی |
| --- | --- |
| `supported` | در API رسمی پشتیبانی می‌شود. |
| `needs-app-review` | برای کاربر واقعی به App Review و Advanced Access نیاز دارد. جایی که منبع Business Verification را هم نام برده، همان قید حفظ شده است. |
| `not-allowed` | در سیاست یا API رسمی مجاز نیست و ساخته نمی‌شود. |
| `internal` | منطق داخل محصول است. اگر ارسال پیام هم لازم باشد، منبع ترکیب را جداگانه نوشته و همان ترکیب در جدول حفظ شده است. |

بعضی ردیف‌های منبع به‌جای یک برچسب، ترکیب یا مقدار `mixed` دارند. آن مقدارها دست‌نخورده مانده‌اند.

## 3. تعریف MVP

نسخه‌ی هر قابلیت را جدول بالا تعیین می‌کند. ردیف‌هایی که نسخه‌شان `MVP` است:

`F-001`، `F-002`، `F-004`، `F-006`، `F-007`، `F-008`، `F-009`، `F-010`، `F-011`، `F-012`، `F-013`، `F-020`، `F-021`، `F-022`، `F-023`، `F-024`، `F-025`، `F-026`.

`F-003` در ستون نسخه `V2` است و قید «RBAC پایه در MVP» دارد. RBAC کامل در UI جزو V2 می‌ماند.

### معیار «MVP تمام شد»

1. یک کسب‌وکار واقعی بتواند ثبت‌نام کند.
2. پیج را رسمی وصل کند.
3. یک اتوماسیون Comment-to-DM بسازد.
4. یک پاسخ خودکار دایرکت بسازد.
5. Inbox را ببیند.
6. لید جمع کند.
7. اشتراک بخرد.
8. Super Admin همه را مانیتور کند.
9. همه‌ی این‌ها روی اپ Meta تأییدشده انجام شود.

این جمله جایگزین ردیف‌های `MVP` جدول نیست. ردیف‌های جدول همچنان داخل MVP هستند، حتی اگر در این نه بند تکرار نشده باشند.

## 4. خارج از محدوده یا ممنوع

این موارد قابلیت برنامه‌ریزی‌شده نیستند.

| مورد | دلیل |
| --- | --- |
| اتصال حساب شخصی (`F-005`) | API رسمی فقط حساب Professional (Business/Creator) را پشتیبانی می‌کند. |
| Cold DM | پیام فقط پس از اقدام کاربر و داخل پنجره مجاز است. |
| پیام انبوه به افرادی که تعامل نکرده‌اند | در موارد پشتیبانی‌نشده‌ی API آمده است. |
| اسکرپ یا استخراج لیست فالوور | لیست فالوور از سال ۲۰۱۸ از API حذف شده است. |
| فالو و آنفالو خودکار | در موارد پشتیبانی‌نشده آمده است. |
| پیام گروهی | Send API پیام گروهی را پشتیبانی نمی‌کند. |
| فالو اجباری (مشروط کردن پاسخ به فالو) | در ردیف `Never` با وضعیت `not-allowed` آمده است. |
| دریافت یا ذخیره‌ی رمز اینستاگرام | اتصال فقط با OAuth رسمی است. |
| استفاده‌ی تبلیغاتی از `HUMAN_AGENT` | این تگ فقط برای پاسخ عامل انسانی است. |
