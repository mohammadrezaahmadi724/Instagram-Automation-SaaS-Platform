# واژه‌نامه

وضعیت سند: پیش‌نویس فاز ۱ب

تاریخ: 1405/09/04

تعریف‌های بدون منبع رسمی در فاز ۰ با `TODO(research)` مانده بودند. تعریف‌هایی که در فاز ۱الف از سند همین تسک یا لینک داده‌شده پر شده‌اند، همان‌جا منبع دارند.

| فارسی | English | تعریف |
| --- | --- | --- |
| فضای کاری / مستأجر | Workspace / Tenant | واحد چندمستأجری محصول. هر رکورد به `workspace_id` تعلق دارد. |
| اتوماسیون | Automation | قاعده‌ی پاسخ با فعال‌کننده و پاسخ. در تحقیق رقیب هسته‌ی مشابه «دستور» نام دارد. |
| فعال‌کننده | Trigger | رویدادی که اتوماسیون را شروع می‌کند؛ مانند پیام دایرکت، کامنت، یا ریپلای استوری. |
| نوع تطبیق | Match type (Exact, Contains, Any) | سه حالت تطبیق کلمه‌ی کلیدی. در تحقیق رقیب سه عبارت «دقیقاً برابر»، «شامل کلمه» و «هر متنی» آمده است. تناظر یک‌به‌یک این عبارت‌ها با Exact و Contains و Any در منبع صریح نیست و **استنباطی** است. |
| پاسخ خصوصی | Private Reply | یک پیام خصوصی برای هر کامنت. پست، ریل و تبلیغ تا ۷ روز؛ لایو فقط حین پخش. ارسال با `POST /{IG_ID}/messages` و `recipient.comment_id`. |
| کامنت به دایرکت | Comment-to-DM | اتوماسیونی که کامنت را با Private Reply به دایرکت می‌برد. |
| پنجره‌ی ۲۴ساعته‌ی پیام | 24-hour messaging window | ارسال دایرکت پس از اقدام کاربر، معمولاً تا ۲۴ ساعت. استثنای منبع: اولین پیام از تبلیغ Click-to-Direct تا ۷ روز، و تگ `HUMAN_AGENT` تا ۷ روز فقط برای پاسخ انسانی. |
| تگ عامل انسانی | HUMAN_AGENT tag | تنها تگ مجاز اینستاگرام. تا ۷ روز و فقط برای پاسخ عامل انسانی. استفاده‌ی تبلیغاتی ممنوع است. |
| یخ‌شکن | Ice Breakers | حداکثر ۴ مورد. روی دسکتاپ نیست. |
| پاسخ سریع | Quick Replies | حداکثر ۱۳ مورد متنی، هر کدام ۲۰ کاراکتر. Quick Reply تلفن و ایمیل برای اینستاگرام غیرفعال است. |
| قالب عمومی | Generic Template | حداکثر ۱۰ کارت، ۳ دکمه‌ی `postback` یا `web_url`، عنوان ۸۰ کاراکتر. روی دسکتاپ نیست. |
| قالب دکمه | Button Template | متن ۶۴۰ کاراکتر و ۱ تا ۳ دکمه. |
| منوی ثابت | Persistent Menu | دکمه‌ی `postback` یا `web_url`. به‌روزرسانی لحظه‌ای ندارد. حداکثر ۵ آیتم توصیه می‌شود. |
| شناسه‌ی کاربر اینستاگرام | IGSID | `IGSID` (Instagram-scoped ID): شناسه‌ی کاربر اینستاگرام که برای هر حساب Professional یکتاست و در webhookهای پیام می‌آید. در Send API به‌شکل `recipient: { id: <IGSID> }` استفاده می‌شود. با `IG_ID`، یعنی شناسه‌ی حساب Professional مشتری ما، فرق دارد. منبع: [Send Messages](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/messaging-api). |
| وب‌هوک | Webhook | رویدادهایی که Meta به URL محصول می‌فرستد؛ از جمله `messages` و `comments`. امضا باید قبل از پردازش بررسی شود. |
| بررسی اپ | App Review | بررسی Meta برای دادن Advanced Access به کاربران واقعی. |
| دسترسی پیشرفته | Advanced Access | سطح دسترسی لازم برای کاربران واقعی. Standard Access فقط برای نقش‌داران اپ کافی است. |
| تأیید کسب‌وکار | Business Verification | تأیید کسب‌وکار Meta. همراه App Review برای کاربران واقعی لازم است. |
| توکن بلندمدت | Long-lived token | توکن اینستاگرام با اعتبار ۶۰ روز. refresh token جداگانه وجود ندارد. توکن short-lived با `ig_exchange_token` به همین توکن تبدیل می‌شود و خود آن با `ig_refresh_token` تمدید می‌شود، اگر دست‌کم ۲۴ ساعت از صدورش گذشته و منقضی نشده باشد. منبع: [توکن‌ها](03-instagram-api-constraints.md#s12). |
| فراخوان حذف داده | Data Deletion Callback | URL ثبت‌شده در Business Login. درخواست `POST` با `signed_request` است و پاسخ JSON شامل `url` و `confirmation_code` می‌خواهد. |
| فراخوان قطع مجوز | Deauthorize Callback | با دریافت آن، اتصال غیرفعال می‌شود، توکن حذف می‌شود و اتوماسیون‌ها متوقف می‌شوند. جزئیات payload **تأییدنشده** است. |
| کنترل دسترسی نقش‌محور | RBAC | نقش‌های حداقل: Super Admin در پلتفرم، و Owner و Admin و Agent و Viewer در Workspace. کنترل سمت سرور است. |
| لاگ ممیزی | Audit Log | ثبت عملیات حساس با زمان، کاربر، IP و tenant. لاگ غیرقابل‌ویرایش است. |
| رکورد تصمیم معماری | ADR | Architecture Decision Record. قالب و فهرست در `04-architecture-decisions.md` است. |
| کمینه‌ی محصول | MVP | مجموعه‌ی قابلیت‌های نسخه‌ی `MVP` در `01-product-scope.md`، به‌علاوه‌ی معیار «MVP تمام شد». |
| مدیر ارشد پلتفرم | Super Admin | نقش سطح پلتفرم، جدا از نقش‌های Workspace. دسترسی آن لاگ می‌شود. |
| لید | Lead | داده‌ای که از فرم جمع می‌شود. فیلدهای دقیق در این فاز تعیین نشده‌اند. |
| مخاطب | Contact | شخص یا حساب مرتبط با Workspace. طرح فیلدها تصمیم معماری باز است و از فرم مخاطب رقیب کپی نمی‌شود. |
| صندوق پیام | Inbox | سطح دیدن گفتگو و پاسخ دستی داخل پنجره‌ی ۲۴ ساعت برای MVP. |
| سازنده‌ی جریان | Flow Builder | سازنده‌ی سناریوی شاخه‌دار. در پیوست قابلیت‌ها نسخه‌ی V2 است. |
| حساب حرفه‌ای | Professional account (Business/Creator) | تنها نوع حساب پشتیبانی‌شده. حساب شخصی `not-allowed` است. |
| مسیریابی گفتگو | Conversation Routing | جایگزین Handover Protocol برای Instagram از ۲۳ اکتبر ۲۰۲۵. کنترل گفتگو را بین اپ ما، Inbox اینستاگرام یا اپ دیگر جابه‌جا می‌کند. جزئیات پیاده‌سازی **تأییدنشده** است. |
| توکن طراحی | Design token | مقدار نام‌دار ظاهر، مثل رنگ یا فاصله یا شعاع. کامپوننت به‌جای عدد خام از نام توکن استفاده می‌کند. فهرست در `09-design-system.md` است. |
| توکن معنایی | Semantic token | توکنی که نقش را نام می‌برد، مثل `--text-primary` یا `--primary`. در تم روشن و تیره مقدار متفاوت می‌گیرد. کامپوننت فقط از این لایه استفاده می‌کند. |
| حالت خالی | Empty state | نمای صفحه‌ای که داده‌ای برای نمایش نیست. عنوان، توضیح و یک CTA واقعی دارد. اسپینر یا جمله‌ی «داده‌ای نیست» به‌تنهایی کافی نیست. |
| ویزارد مرحله‌ای | Stepper / Wizard | جریان مرحله‌ای، در این محصول برای ساخت اتوماسیون. هر مرحله اعتبارسنجی می‌شود و پیشرفت در RTL از راست به چپ است. |
| پیش‌نمایش زنده | Live preview | قاب گوشی اختصاصی محصول که پیام کاربر و پاسخ خودکار را هم‌زمان با نوشتن نشان می‌دهد. کپی رابط اینستاگرام نیست. |
| اعلان کوتاه | Toast | بازخورد گذرا بعد از یک اقدام، مثل موفقیت یا خطا. جای محتوای صفحه را نمی‌گیرد. |
| اسکلت بارگذاری | Skeleton | جای‌نگهدار هم‌شکل همان محتوا در حالت `loading`. جایگزین spinner تمام‌صفحه است. |
| دایرکتورا | Directora | نام محصول. فارسی «دایرکتورا» و لاتین «Directora». تصمیم مالک در ۱۴۰۵/۰۹/۰۴، ثبت‌شده در ADR-014. دامنه جدا است و در ADR-016 هنوز باز است. |
| توکن گرادیان | Gradient token | گرادیان نام‌دار، مثل `--gradient-brand`. تزئینی است. روی گرادیان برند متن قرار نمی‌گیرد. جهت گرادیان در RTL آینه نمی‌شود. |
| مرز فیلد | Border-input | توکن `--border-input`. رنگ مرز `Input`، `Select` و `Checkbox` با کنتراست غیرمتنی حداقل ۳:۱ نسبت به سطح (WCAG 1.4.11). در هر دو تم `ink-450` است. |
| پلاک برند | Brand plate | سطح `ink-0` با `radius-lg` و padding که لوگوی سرمه‌ای در تم تیره روی آن دیده شود، تا نسخه‌ی روشن لوگو آماده شود. |
