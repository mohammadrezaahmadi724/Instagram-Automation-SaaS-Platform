## 4. ریسک‌ها

- App Review و Business Verification مسیر بحرانی‌اند. بدون Advanced Access، کاربر واقعی، webhook زنده، و Human Agent کار نمی‌کنند.
- ایران و تحریم **تأییدنشده** است. نتیجه‌ی منفی می‌تواند فاز ۲ را `مسدود` کند.
- پنجره‌ی ۲۴ ساعته ارسال دایرکت را محدود می‌کند. استثناها فقط موارد صریح سند API هستند، از جمله Click-to-Direct و `HUMAN_AGENT` با همان قیدها.
- اگر سرور به `graph.instagram.com` و `graph.facebook.com` دسترسی پایدار نداشته باشد، اتصال و ارسال قابل اتکا نیست. برقراری این دسترسی از ایران **تأییدنشده** است.
