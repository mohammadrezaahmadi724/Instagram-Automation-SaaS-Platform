# چک‌لیست راه‌اندازی

تاریخ: ۱۴۰۵/۰۹/۰۶

این فهرست برای مالک است. دامنه هنوز تصمیم باز ADR-016 است و App Review متا هم هنوز باز است.

1. دامنه و HTTPS را انتخاب و وصل کنید. تا Accepted شدن ADR-016، دامنه در محصول فرض گرفته نمی‌شود.
2. روی VPS، Docker Compose تولید را برای web، worker، Postgres و Redis بالا بیاورید. پورت‌های توسعهٔ 55432 و 56379 فقط برای همین ماشین محلی‌اند.
3. متغیرها را از `.env.example` پر کنید و مقدار واقعی را commit نکنید. `ENCRYPTION_KEY` را با ۳۲ بایت تصادفی بسازید، مثلاً خروجی `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. `AUTH_SECRET` را هم با همین روش و دست‌کم ۱۶ نویسه بسازید. هیچ‌کدام را در سند یا چت ننویسید.
4. `pnpm db:migrate:deploy` سپس `pnpm db:seed` سپس `pnpm admin:promote -- +98...` را بزنید. اسکریپت کاربر موجود را مدیر پلتفرم می‌کند و کاربر تازه نمی‌سازد.
5. وارد `/admin/settings` شوید و شماره کارت، شبا و نام صاحب حساب واقعی را ثبت کنید.
6. پیامک تولید (کاوه‌نگار، ملی‌پیامک یا SMS.ir) وقتی آماده شد وصل می‌شود. تا آن زمان `SMS_PROVIDER=console` فقط برای توسعه است. ADR-008 همچنان Proposed است.
7. اپ Meta Developer را بسازید و URLهای OAuth، Webhook، Deauthorize و Data Deletion را ثبت کنید. برای کاربر واقعی، App Review هنوز لازم است و این چک‌لیست آن را انجام‌شده فرض نمی‌کند.
